# Vishal Lovanshi Portfolio

Modern frontend developer portfolio built with React, Vite and Tailwind CSS.

## Run Locally

```bash
npm install --cache /workspace/.npm-cache
npm run dev -- --host 127.0.0.1 --port 5173
```

## Build

```bash
npm run build
```
